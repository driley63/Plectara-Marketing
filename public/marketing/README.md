Device PNGs include the phone bezel. Drop a file into this folder using the filename above; the homepage picks it up automatically.

The yarn WebP is copied unchanged from the approved PL-OS app visual kit at
`assets/app/plectara/textures/plectara-widget-yarn-gentle-focus-v1.webp`.
The current device and widget PNGs depict an earlier visual treatment. Replace
them with truthful captures of the finished app and widgets before promoting
the re-themed site publicly. The download section uses a brand-color gradient
until verified lifestyle photography is supplied. New photography can be added
later without changing the page layout.

PNG screenshots must retain their RGBA alpha channel, including partially transparent pixels along curved edges. Do not flatten them, threshold their alpha, or bake a transparency checkerboard into the artwork. Device edge smoothing changes only a two-pixel band around the exterior; the screen content and interior bezel remain unchanged.
