# Marketing imagery

| File | Use |
| --- | --- |
| `hero-daily-habits.jpg` | Hero background for the product philosophy headline |
| `widget-small.png` | Small Home Screen widget (one-tap capture). Stub on `/#widgets` until added |
| `widget-medium.png` | Medium Home Screen widget (habits and suggestions). Stub on `/#widgets` until added |
| `widget-large.png` | Large Home Screen widget. Stub on `/#widgets` until added |

Device photos (Today, Timeline, Insights on a real phone) are dashed slots on the homepage until camera shots are added here.

Drop a widget PNG into this folder using the filename above. The homepage widgets section picks it up automatically and replaces the dashed stub.
