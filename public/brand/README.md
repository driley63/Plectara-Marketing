# Brand assets

Plectara lockups, symbol, and app tile from [PL-OS / LIQ-OS](https://liq-os.lifestyleiq.io/specs/01-brand/plectara-brand-kit/) (brand kit v2.0.0, approved 2026-09-04). Do not recreate the wordmark with a font.

| File | Use |
| --- | --- |
| `plectara-horizontal.png` / `.svg` | Header lockup on ivory or white |
| `plectara-horizontal-reversed.png` / `.svg` | Footer lockup on ink |
| `plectara-symbol.svg` | Vector favicon |
| `plectara-512.png` / `plectara-1024.png` | Raster favicon, Apple touch icon, JSON-LD |
| `plectara-app-icon.png` / `.svg` | Opaque 1024 app tile |
| `plectara-social-card.png` | Open Graph / Twitter (1200 × 630) |
| `plectara-symbol-white.png` | Dark-surface symbol if needed |
| `favicon.ico` | Legacy favicon |

Use ink lettering on ivory/white and the reversed lockup on ink. Keep at least 140 px width for the horizontal digital lockup.
